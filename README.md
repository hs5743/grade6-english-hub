# 🎓 國小六年級英語核心能力檢核與自學系統 (Grade 6 English Core Hub)

對齊中華民國教育部 **108 課綱國小高年級（第 7–8 冊）** 英語文領域全國核心學習內容，結合 **CEFR A1+**、**Cambridge YLE Movers** 與 **TOEFL Primary Step 1** 國際標準所打造的互動自學與核心能力診斷平台。

🌐 **線上立即體驗 (GitHub Pages)**：  
👉 **[https://hs5743.github.io/grade6-english-hub/](https://hs5743.github.io/grade6-english-hub/)**

---

## ✨ 系統五大核心功能

1. **🏰 冒險總覽與漸進式導覽 (Progressive Disclosure UI)**
   - 採用低視覺負擔卡片設計，補充說明支援點擊展開／收合，並搭配 3D 英語探險小狐狸吉祥物與 XP 等級徽章系統。
2. **🃏 主題單字魔法卡館 (Vocabulary Flashcards)**
   - 涵蓋高年級 8 大核心主題、共 **64 個必備單字與片語**，內建真人美語雙速朗讀 (Web Speech API)、例句點讀與「聽音選字快篩遊戲」。
3. **⚡ 核心句型與文法互動實驗室 (Interactive Grammar Lab)**
   - 整理 **6 大高年級核心句型與時態**（現在簡單式第三人稱單數、國籍與交通方式、生病關懷與點餐志向、服飾價格單複數、Be 動詞過去式 `was/were`、一般動詞過去式 `did/-ed`），提供彩色積木公式、漸進式對照表與隨堂闖關練習。
4. **💬 沉浸式漫畫對話與閱讀聽力工坊 (Interactive 4-Panel Comic Reader)**
   - 收錄 **4 篇原創生活與跨文化情境對話**，每篇皆配備 **AI 原創 4 格全彩教育漫畫插圖**，支援點擊漫畫分格同步發音點讀、全篇連播、單句中文翻譯切換與閱讀理解挑戰。
5. **🏆 24 題綜合診斷測驗與六維度雷達圖處方箋 (Diagnostic Assessment)**
   - 支援四大檢測模式（全能力 24 題、過去式雙軌專項、單字現在式專項、錯題本復仇），測驗後自動繪製 **六大能力維度 SVG 雷達圖**，並提供一鍵導流的「個人化弱點強化處方箋」與榮譽合格證書列印功能。
