# 🎓 國小六年級英語核心能力檢核與自學系統 (Grade 6 English Core Hub)

對齊臺灣 **108 課綱國小高年級（第 7–8 冊）** 主流英語教材（康軒版《Wonder World 7–8》與翰林版《Here We Go! 7–8》），結合 **CEFR A1+**、**Cambridge YLE Movers** 與 **TOEFL Primary Step 1** 國際標準所打造的互動自學與核心能力診斷平台。

🌐 **線上立即體驗 (GitHub Pages)**：  
👉 **[https://hs5743.github.io/grade6-english-hub/](https://hs5743.github.io/grade6-english-hub/)**

## ✨ 系統五大核心功能

1. **🏠 學習總覽與漸進式導覽 (Progressive Disclosure UI)**
   - 採用低視覺負擔卡片設計，補充說明支援點擊展開／收合，並搭配 3D 英語探險小狐狸吉祥物與 XP 等級徽章系統。
2. **🃏 主題單字翻翻卡與拼字微挑戰 (Vocabulary Flashcards)**
   - 涵蓋第 7–8 冊 8 大核心主題、共 **64 個必備單字**，內建真人語音朗讀 (Web Speech API)、3D 翻轉例句與「聽音辨字／拼字填空」練習。
3. **🧩 互動文法實驗室 (Interactive Grammar Lab)**
   - 整理 **6 大高年級核心句型與時態**（頻率副詞、過去進行式、一般過去式規則與不規則動詞、未來計畫 `be going to`、天氣與交通介系詞），提供漸進式手風琴展開與即時微測驗。
4. **📖 情境有聲漫畫閱讀館 (Comic Story Reader)**
   - 收錄 **4 篇跨文化與生活長篇情境對話**，支援整篇連播、單句點讀、中英對照切換與閱讀理解小測驗。
5. **🎯 24 題綜合診斷測驗與六維度雷達圖處方箋 (Diagnostic Assessment)**
   - 包含單選、聽音辨義、句子重組、克漏字填空四種題型，測驗後自動繪製 **六大能力維度 SVG 雷達圖**，並提供一鍵跳轉的「個人化弱點強化處方箋」與認證獎盃證書列印功能。
