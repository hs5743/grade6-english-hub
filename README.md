## ✨ 系統五大核心功能（V6 完整教材與高階會話版）

1. **🏰 冒險總覽與漸進式導覽 (Progressive Disclosure UI)**
   - 採用低視覺負擔卡片設計，補充說明支援點擊展開／收合，並搭配 3D 英語探險小狐狸吉祥物與 XP 等級徽章系統。
2. **🃏 主題單字魔法卡館 (96 個兩版本完整詞彙與高階句型)**
   - 100% 囊括兩套第 7–8 冊教材 8 大主題、共 **96 個核心單字、片語與課本高階慣用語**（涵蓋國家與文化、生病症狀與疼痛表達 `hurts / don't feel well`、交通與安全、作息與 8 大餐飲可數/不可數名詞、兩版所有休閒活動、8 大夢想職業與價值使命、9 大服飾計價與 `Whose` 所有權、四季氣候 `dry/wet/foggy/snowy` 與過去時間副詞 `ago/yesterday/last night`），內建真人美語雙速朗讀與「聽音選字快篩遊戲」。
3. **⚡ 核心句型與高階文法互動實驗室 (8 大句構模組)**
   - 完整收錄兩套教材涵蓋的 **8 大基礎與高層次句型**：
     - 單元 1：現在簡單式與第三人稱單數 (`does / -s / -es / -ies`)
     - 單元 2：國籍來源 (`Where... from`) vs. 交通方式 (`How... go to` / `can get to... by`)
     - 單元 3：生病關懷 (`What's wrong? / hurts`)、委婉點餐 (`Would you like...`) 與職業志向 (`want to be`)
     - 單元 4：服飾購物與單複數價格一致性 (`How much is/are...`)
     - 單元 5：Be 動詞過去式 (`was / were`) 與過去時間副詞 (`an hour ago / two days ago`)
     - 單元 6：一般動詞過去式 (`did / -ed`) 雙軌銜接
     - 單元 7：**可數與不可數食物名詞 (`some + 不可數 / 可數複數`) 與物品所有權 (`Whose is/are...`)**
     - 單元 8：**高層次會話與寫作句構（動名詞作主詞 `Camping is fun!`、感嘆句 `What a...!`、`can't wait to V`、序列詞 `First/Next/Then/Finally` 與職業使命表達）**
4. **💬 沉浸式漫畫對話與閱讀聽力工坊 (Interactive 4-Panel Comic Reader)**
   - 收錄 **4 篇融合課本高層次會話表現的原創生活對話**（包含 `"I could eat a horse!"`、`"My plate is full."`、`"You don't look well."`、`"What a big dinosaur!"`、`"I can't wait to..."`、`"Camping is fun!"` 等道地用語），每篇皆配備 **AI 原創 4 格全彩教育漫畫插圖**，支援點擊漫畫分格同步發音點讀、全篇連播、單句中文翻譯切換與閱讀理解挑戰。
5. **🏆 30 題綜合自我檢測與六維度雷達圖處方箋 (Self-Assessment)**
   - 支援四大檢測模式（全範圍 30 題、過去式雙軌專項、單字現在式專項、錯題本複習），除基礎字彙與文法外，特別納入課本 **Reading Skills 高層次閱讀邏輯推論題 (Making Inferences)**、**序列組織題 (Sequence & Timeline)** 與 **高階會話語境推論題**，測驗後自動繪製 **六大能力維度 SVG 雷達圖** 並提供個人化複習處方箋。
